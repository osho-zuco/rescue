## Tech Stack

### Backend

| Layer | Technology | Why |
|-------|------------|-----|
| Runtime | **Bun** | Fast, TypeScript-native, built-in test runner |
| Framework | **Hono** | Lightweight, fast, excellent middleware support |
| Database | **PostgreSQL** | Reliable, PostGIS for location, JSON support |
| ORM | **Prisma** | Type-safe queries, migrations, great DX |
| Validation | **Zod** | Runtime type checking, schema inference |
| Auth | **Custom OTP** | Full control, provider abstraction |

### Flutter Apps

| Layer | Technology | Why |
|-------|------------|-----|
| State | **BLoC** | Predictable, testable, separation of concerns |
| DI | **GetIt** | Simple service locator, lazy singletons |
| Routing | **go_router** | Declarative, deep linking support |
| Code Gen | **Freezed** | Immutable models, union types |
| HTTP | **Dio** | Interceptors, request cancellation |

### External Services

| Service | Provider | Purpose |
|---------|----------|---------|
| OTP | Twilio / MSG91 | Phone verification |
| Payments | Razorpay / Cashfree | Merchant subscriptions |
| Push | Firebase Cloud Messaging | Notifications |
| Storage | Cloudinary | Image uploads |

## Design Patterns

### 1. Result Pattern (No Throwing)

Instead of throwing exceptions, all fallible operations return `Result<T, E>`.

```typescript
// backend/src/lib/result.ts
type Result<T, E> = Ok<T> | Err<E>;

// Usage in services
async function collectStamp(userId: string, merchantId: string): Promise<Result<Stamp, StampError>> {
  const merchant = await db.merchant.findUnique({ where: { id: merchantId } });
  if (!merchant) {
    return err({ code: 'MERCHANT_NOT_FOUND', message: 'Merchant not found' });
  }

  // Check daily limit
  const todayStamp = await db.stamp.findFirst({
    where: {
      userId,
      merchantId,
      scannedAt: { gte: startOfDay(new Date()) }
    }
  });

  if (todayStamp) {
    return err({ code: 'DAILY_LIMIT_REACHED', message: 'Already collected stamp today' });
  }

  const stamp = await db.stamp.create({ ... });
  return ok(stamp);
}

// Usage in routes
app.post('/stamps', async (c) => {
  const result = await collectStamp(userId, merchantId);

  return result.match({
    ok: (stamp) => apiSuccess(c, stamp, 201),
    err: (error) => apiError(c, error)
  });
});
```

**Flutter equivalent:**
```dart
// packages/druto_core/lib/error/result.dart
sealed class Result<T, E> {
  const Result();

  R when<R>({
    required R Function(T data) ok,
    required R Function(E error) err,
  });
}

// Usage in repository
Future<Result<Stamp, ApiError>> collectStamp(String merchantId) async {
  try {
    final response = await dio.post('/stamps', data: {'merchantId': merchantId});
    return Ok(Stamp.fromJson(response.data['data']));
  } catch (e, stackTrace) {
    Log.e('Failed to collect stamp', error: e, stackTrace: stackTrace);
    return Err(ApiError.fromDioError(e));
  }
}

// Usage in BLoC
final result = await repository.collectStamp(merchantId);
result.when(
  ok: (stamp) => emit(StampCollected(stamp)),
  err: (error) => emit(StampError(error.message)),
);
```

### 2. Provider Abstraction (SOLID)

External services are abstracted behind interfaces for testability and flexibility.

#### OTP Provider

```typescript
// backend/src/services/otp/IOtpProvider.ts
interface IOtpProvider {
  sendOtp(phone: string): Promise<Result<OtpSendResult, OtpError>>;
  verifyOtp(phone: string, otp: string): Promise<Result<boolean, OtpError>>;
}

// backend/src/services/otp/TwilioProvider.ts
class TwilioProvider implements IOtpProvider {
  async sendOtp(phone: string): Promise<Result<OtpSendResult, OtpError>> {
    // Twilio Verify API implementation
  }
}

// backend/src/services/otp/Msg91Provider.ts
class Msg91Provider implements IOtpProvider {
  async sendOtp(phone: string): Promise<Result<OtpSendResult, OtpError>> {
    // MSG91 implementation
  }
}

// Factory pattern for provider selection
function getOtpProvider(): IOtpProvider {
  switch (config.otpProvider) {
    case 'twilio': return new TwilioProvider();
    case 'msg91': return new Msg91Provider();
    default: throw new Error('Unknown OTP provider');
  }
}
```

#### Payment Gateway

```typescript
// backend/src/services/gateways/IPaymentGateway.ts
interface IPaymentGateway {
  createSubscription(params: CreateSubscriptionParams): Promise<Result<Subscription, PaymentError>>;
  getSubscription(subscriptionId: string): Promise<Result<Subscription, PaymentError>>;
  cancelSubscription(subscriptionId: string): Promise<Result<void, PaymentError>>;
  verifyWebhookSignature(payload: string, signature: string): boolean;
}

// Implementations: RazorpayGateway, CashfreeGateway
```

**Benefits:**
- Switch providers without changing business logic
- Easy to mock for testing
- Can run A/B tests between providers
- Graceful degradation (fallback to secondary provider)

### 3. Role-Based Authorization

```typescript
// backend/src/middleware/auth.ts
type UserRole = 'CUSTOMER' | 'MERCHANT_OWNER' | 'ADMIN';

// JWT payload includes role
interface JWTPayload {
  userId: string;
  role: UserRole;
}

// Middleware for role checking
export function requireRole(...roles: UserRole[]) {
  return async (c: Context, next: Next) => {
    const userRole = c.get('role') as UserRole;
    if (!roles.includes(userRole)) {
      return apiError(c, Errors.FORBIDDEN);
    }
    await next();
  };
}

// Usage in routes
app.post('/merchants', authMiddleware, requireRole('MERCHANT_OWNER', 'ADMIN'), createMerchant);
app.get('/admin/stats', authMiddleware, requireRole('ADMIN'), getAdminStats);
```

## API Design

### RESTful Conventions

```
GET    /merchants           # List merchants
POST   /merchants           # Create merchant
GET    /merchants/:id       # Get merchant
PATCH  /merchants/:id       # Update merchant
DELETE /merchants/:id       # Delete merchant

GET    /merchants/:id/rewards    # List merchant's rewards
POST   /merchants/:id/rewards    # Create reward for merchant
```

### Response Format

```typescript
// Success
{
  "success": true,
  "data": { ... },
  "meta": {
    "requestId": "abc123",
    "timestamp": "2024-01-15T10:30:00Z"
  }
}

// Error
{
  "success": false,
  "error": {
    "code": "DAILY_LIMIT_REACHED",
    "message": "You've already collected a stamp today. Come back tomorrow!"
  },
  "meta": {
    "requestId": "abc123",
    "timestamp": "2024-01-15T10:30:00Z"
  }
}
```

### API Versioning

All routes prefixed with `/api/v1/`. Breaking changes require new version.

```typescript
const v1 = new Hono();
v1.route('/auth', authRoutes);
v1.route('/merchants', merchantRoutes);
v1.route('/stamps', stampRoutes);

app.route('/api/v1', v1);
```

## Security

### Input Validation

All inputs validated with Zod before processing:

```typescript
const collectStampSchema = z.object({
  merchantId: z.string().uuid(),
  latitude: z.number().min(-90).max(90),
  longitude: z.number().min(-180).max(180),
});

app.post('/stamps/collect', async (c) => {
  const body = await c.req.json();
  const validation = collectStampSchema.safeParse(body);

  if (!validation.success) {
    return apiError(c, Errors.VALIDATION_ERROR, validation.error);
  }

  // Proceed with validated data
});
```

### Rate Limiting

```typescript
// Per-IP rate limiting
app.use('*', rateLimiter({
  windowMs: 60 * 1000,  // 1 minute
  max: 100,             // 100 requests per minute
}));

// Stricter limit for auth endpoints
app.use('/auth/*', rateLimiter({
  windowMs: 60 * 1000,
  max: 10,              // 10 OTP requests per minute
}));
```

### JWT Security

- Short-lived access tokens (15 minutes)
- Refresh tokens stored securely (7 days)
- Tokens invalidated on password change
- Role encoded in token, verified on each request

## Error Handling

### Backend Error Codes

```typescript
// backend/src/lib/errors.ts
export const Errors = {
  // Auth
  INVALID_OTP: { code: 'INVALID_OTP', status: 401, message: 'Invalid or expired OTP' },
  TOKEN_EXPIRED: { code: 'TOKEN_EXPIRED', status: 401, message: 'Token expired' },

  // Merchant
  MERCHANT_NOT_FOUND: { code: 'MERCHANT_NOT_FOUND', status: 404, message: 'Merchant not found' },
  MERCHANT_NOT_OWNER: { code: 'MERCHANT_NOT_OWNER', status: 403, message: 'Not the merchant owner' },

  // Stamp
  DAILY_LIMIT_REACHED: { code: 'DAILY_LIMIT_REACHED', status: 429, message: 'Already collected stamp today' },
  OUT_OF_RANGE: { code: 'OUT_OF_RANGE', status: 400, message: 'Please visit the restaurant to collect stamp' },
  REWARD_NOT_ACTIVE: { code: 'REWARD_NOT_ACTIVE', status: 400, message: 'This reward is no longer available' },

  // Redemption
  NOT_ENOUGH_STAMPS: { code: 'NOT_ENOUGH_STAMPS', status: 400, message: 'Not enough stamps to redeem' },
  ALREADY_REDEEMED: { code: 'ALREADY_REDEEMED', status: 400, message: 'Already redeemed' },
} as const;
```

### Flutter Error Handling

```dart
// In repository layer (catch and log)
Future<Result<Stamp, ApiError>> collectStamp(String merchantId, Position position) async {
  try {
    final response = await dio.post('/stamps/collect', data: {
      'merchantId': merchantId,
      'latitude': position.latitude,
      'longitude': position.longitude,
    });
    return Ok(Stamp.fromJson(response.data['data']));
  } catch (e, stackTrace) {
    Log.e('Failed to collect stamp', error: e, stackTrace: stackTrace);
    return Err(ApiError.fromDioError(e));
  }
}

// In presentation layer (no try-catch, use Result)
final result = await repository.collectStamp(merchantId, position);
result.when(
  ok: (stamp) => showSuccessDialog(stamp),
  err: (error) => showErrorSnackbar(error.message),
);
```
