## Models Reference

### User

Represents both customers and merchant owners.

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Primary key |
| `phone` | String | Unique phone number (+91...) |
| `name` | String? | Display name |
| `profilePhotoUrl` | String? | Avatar URL |
| `role` | Enum | CUSTOMER, MERCHANT_OWNER, ADMIN |
| `createdAt` | DateTime | Account creation time |
| `updatedAt` | DateTime | Last update time |

**Indexes:** `phone`, `role`

**Role Notes:**
- Users start as `CUSTOMER`
- Upgraded to `MERCHANT_OWNER` when they create a merchant
- `ADMIN` is set manually in DB

---

### Merchant

Restaurant, cafe, or business offering rewards.

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Primary key |
| `ownerId` | UUID | FK → User |
| `name` | String | Business name |
| `description` | String? | About the business |
| `logoUrl` | String? | Square logo |
| `coverPhotoUrl` | String? | Banner image |
| `latitude` | Decimal | GPS latitude |
| `longitude` | Decimal | GPS longitude |
| `address` | String | Full address |
| `city` | String | City name (for filtering) |
| `upiId` | String? | UPI VPA for payments |
| `isActive` | Boolean | Visible to customers |
| `isVerified` | Boolean | KYC completed |
| `subscriptionStatus` | Enum | TRIAL, ACTIVE, PAST_DUE, CANCELLED, EXPIRED |
| `subscriptionEndsAt` | DateTime? | Current period end |
| `totalCustomers` | Int | Denormalized count |
| `totalStamps` | Int | Denormalized count |
| `totalRedemptions` | Int | Denormalized count |
| `avgRating` | Decimal | Denormalized average |

**Indexes:** `[latitude, longitude]`, `city`, `[isActive, isVerified]`, `ownerId`

**Subscription Status Flow:**
```
TRIAL (14 days) → ACTIVE (paid)
                     ↓
              PAST_DUE (grace)
                     ↓
              CANCELLED/EXPIRED
```

---

### Reward

Loyalty reward configuration set by merchant.

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Primary key |
| `merchantId` | UUID | FK → Merchant |
| `title` | String | "Free Coffee", "20% Off" |
| `description` | String? | Terms/conditions |
| `imageUrl` | String? | Reward image |
| `stampsRequired` | Int | Stamps needed (5, 8, 10) |
| `expiryDays` | Int? | Days until stamps expire (null = never) |
| `requiresMinPurchase` | Boolean | Needs min purchase per visit |
| `minPurchaseAmount` | Int? | Min amount in ₹ |
| `isActive` | Boolean | Available for new cards |

**Indexes:** `[merchantId, isActive]`

**Common Configurations:**

| Type | Stamps | Expiry | Example |
|------|--------|--------|---------|
| Quick | 5 | 30 days | "5 coffees = 1 free" |
| Standard | 8 | 60 days | "8 visits = free meal" |
| Premium | 10 | null | "10 visits = ₹500 off" |

---

### StampCard

Customer's progress toward a specific reward. Created when customer first scans at a merchant.

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Primary key |
| `userId` | UUID | FK → User |
| `merchantId` | UUID | FK → Merchant |
| `rewardId` | UUID | FK → Reward |
| `lockedStampsRequired` | Int | Snapshot at creation |
| `lockedRewardTitle` | String | Snapshot at creation |
| `lockedExpiryDays` | Int? | Snapshot at creation |
| `currentStamps` | Int | Current progress |
| `startedAt` | DateTime | First stamp time |
| `expiresAt` | DateTime? | Card expiry (if applicable) |
| `status` | Enum | IN_PROGRESS, READY_TO_REDEEM, REDEEMED, EXPIRED |

**Indexes:** `[userId, status]`, `merchantId`, `expiresAt`

**Unique Constraint:** `[userId, rewardId, status]` - One active card per reward

**Status Transitions:**
```
IN_PROGRESS ──[stamps complete]──→ READY_TO_REDEEM
     │                                    │
     │                             [user redeems]
     │                                    │
     └────[card expires]──→ EXPIRED       ▼
                                      REDEEMED
```

**Why Locked Fields?**

If merchant changes reward from "5 stamps = Free Coffee" to "8 stamps = Free Tea", existing cards keep original terms. This prevents bait-and-switch and builds trust.

---

### Stamp

Individual stamp/visit record.

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Primary key |
| `stampCardId` | UUID | FK → StampCard |
| `userId` | UUID | FK → User |
| `merchantId` | UUID | FK → Merchant |
| `scannedAt` | DateTime | When stamp was collected |
| `latitude` | Decimal? | User's location |
| `longitude` | Decimal? | User's location |
| `stampNumber` | Int | Which stamp (1st, 2nd, etc.) |

**Indexes:** `[userId, merchantId, scannedAt]`, `stampCardId`

**Location Storage:**

We store the user's location at scan time for:
1. Fraud detection (pattern analysis)
2. Debugging geofence issues
3. Analytics (where do customers scan from?)

---

### Redemption

Record of a claimed reward.

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Primary key |
| `stampCardId` | UUID | FK → StampCard (1:1) |
| `userId` | UUID | FK → User |
| `merchantId` | UUID | FK → Merchant |
| `rewardId` | UUID | FK → Reward |
| `redemptionCode` | String | 6-char code for merchant |
| `redeemedAt` | DateTime | When user initiated |
| `verifiedByMerchant` | Boolean | Merchant confirmed |
| `verifiedAt` | DateTime? | Verification time |

**Indexes:** `userId`, `merchantId`, `redemptionCode`

**Redemption Flow:**
1. User taps "Redeem" → `redemptionCode` generated
2. User shows code to merchant
3. Merchant enters code in their app
4. `verifiedByMerchant = true`, `verifiedAt = now()`

---

### Review

Customer reviews for merchants.

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Primary key |
| `merchantId` | UUID | FK → Merchant |
| `userId` | UUID | FK → User |
| `rating` | Int | 1-5 stars |
| `comment` | String? | Optional text |

**Indexes:** `merchantId`

**Unique Constraint:** `[merchantId, userId]` - One review per customer per merchant

---

### SubscriptionPayment

Payment records for merchant subscriptions.

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Primary key |
| `merchantId` | UUID | FK → Merchant |
| `gatewayProvider` | String | 'razorpay' or 'cashfree' |
| `gatewaySubscriptionId` | String? | Gateway's subscription ID |
| `gatewayPaymentId` | String? | Gateway's payment ID |
| `amount` | Int | In paise (₹499 = 49900) |
| `status` | Enum | PENDING, CAPTURED, FAILED, REFUNDED |
| `periodStart` | DateTime | Billing period start |
| `periodEnd` | DateTime | Billing period end |

**Indexes:** `merchantId`, `gatewaySubscriptionId`

## API Endpoints

Base URL: `/api/v1`

### Authentication

#### Send OTP
```http
POST /auth/otp/send
```

**Request:**
```json
{
  "phone": "+919876543210"
}
```

**Response (200):**
```json
{
  "success": true,
  "data": {
    "message": "OTP sent successfully"
  }
}
```

**Errors:**
- `RATE_LIMITED` - Too many OTP requests

---

```http
POST /auth/otp/verify
```

**Request:**

{
  "phone": "+919876543210",

**Errors:**
- `INVALID_OTP` - Wrong or expired OTP

### Stamps

#### Collect Stamp
```http
POST /stamps/collect
Authorization: Bearer <token>
```

**Request:**
```json
{
  "merchantId": "uuid",
  "rewardId": "uuid",
  "latitude": 12.9716,
  "longitude": 77.5946
}
```

**Response (201):**
```json
{
  "success": true,
  "data": {
    "stamp": {
      "id": "uuid",
      "stampNumber": 3,
      "scannedAt": "2024-01-15T10:30:00Z"
    },
    "stampCard": {
      "id": "uuid",
      "currentStamps": 3,
      "lockedStampsRequired": 5,
      "lockedRewardTitle": "Free Coffee",
      "status": "IN_PROGRESS"
    },
    "isComplete": false
  }
}
```

**When Complete (5/5):**
```json
{
  "success": true,
  "data": {
    "stamp": { ... },
    "stampCard": {
      "currentStamps": 5,
      "lockedStampsRequired": 5,
      "status": "READY_TO_REDEEM"
    },
    "isComplete": true
  }
}
```

**Validation:**
1. Merchant exists and is active
2. Reward is active
3. User is within 50m of merchant location
4. User hasn't collected stamp today from this merchant

**Errors:**
- `MERCHANT_NOT_FOUND` - Invalid merchant ID
- `REWARD_NOT_ACTIVE` - Reward deactivated
- `OUT_OF_RANGE` - User too far from merchant
- `DAILY_LIMIT_REACHED` - Already stamped today

## Error Codes Reference

| Code | HTTP | Description |
|------|------|-------------|
| `VALIDATION_ERROR` | 400 | Invalid request body |
| `INVALID_OTP` | 401 | Wrong or expired OTP |
| `TOKEN_EXPIRED` | 401 | JWT expired |
| `UNAUTHORIZED` | 401 | Missing auth token |
| `FORBIDDEN` | 403 | Not authorized for action |
| `MERCHANT_NOT_FOUND` | 404 | Invalid merchant ID |
| `REWARD_NOT_FOUND` | 404 | Invalid reward ID |
| `STAMP_CARD_NOT_FOUND` | 404 | Invalid stamp card ID |
| `OUT_OF_RANGE` | 400 | User too far from merchant |
| `DAILY_LIMIT_REACHED` | 429 | Already stamped today |
| `REWARD_NOT_ACTIVE` | 400 | Reward deactivated |
| `NOT_ENOUGH_STAMPS` | 400 | Card not complete |
| `ALREADY_REDEEMED` | 400 | Already used |
| `CARD_EXPIRED` | 400 | Stamp card expired |
| `RATE_LIMITED` | 429 | Too many requests |
| `INTERNAL_ERROR` | 500 | Server error |

## Webhooks (Incoming)

### Razorpay Subscription Webhook
```http
POST /webhooks/razorpay
X-Razorpay-Signature: <signature>
```

**Events Handled:**
- `subscription.activated` - Mark subscription active
- `subscription.charged` - Record payment
- `subscription.cancelled` - Mark cancelled
- `payment.failed` - Mark past due
