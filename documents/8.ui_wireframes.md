# Druto - UI Wireframes

## Design System

### Color Palette

```
Primary:    #FF6B6B (Coral Red) - CTAs, stamps, urgency
Secondary:  #4ECDC4 (Mint Teal) - Success, rewards, freshness
Tertiary:   #2C3E50 (Navy)      - Text, trust, sophistication
Warning:    #FFE66D (Soft Yellow)
Star:       #FFD93D (Golden)

Light Theme:
  Background: #FAFAFA
  Surface:    #FFFFFF
  OnSurface:  #2C3E50

Dark Theme:
  Background: #1A1A2E
  Surface:    #16213E
  OnSurface:  #FFFFFF
```

### Typography

```
Display:    Space Grotesk (or system default)
Body:       Inter (or system default)

Sizes:
  H1: 28sp/700
  H2: 24sp/600
  H3: 20sp/600
  Body: 16sp/400
  Caption: 12sp/400
```

### Spacing

```
xs: 4dp
sm: 8dp
md: 12dp
lg: 16dp
xl: 24dp
xxl: 32dp
```

### Border Radius

```
sm: 8dp  (buttons, inputs)
md: 12dp (cards)
lg: 16dp (sheets)
full: 999dp (pills, avatars)
```

## Animations

### Stamp Collection
1. QR detected → Bottom sheet slides up
2. UPI app selected → Return to app
3. Stamp appears with "plop" + haptic
4. Progress bar fills with bounce
5. If complete → Confetti + celebration

### Reward Unlock
1. Screen dims
2. Reward card scales up from center
3. Confetti burst
4. "REWARD UNLOCKED" text animates in
5. Strong haptic feedback

### Tab Transitions
- Cross-fade between tabs
- No slide animations (feels faster)
